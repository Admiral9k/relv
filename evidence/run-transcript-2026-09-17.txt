Goblin Tools is a free web suite of single-purpose LLM mini-tools by Bram De Buyser, aimed at neurodivergent users but broadly useful, with no account requirement and a free web tier. The flagship, Magic ToDo, recursively decomposes a task into verb-noun substeps, with a 'spiciness' slider serving as a single scalar that controls how granular each decomposition pass gets; subtasks can themselves be re-decomposed. Supporting micro-tools share the same backend pattern: Compiler converts unstructured brain dumps into organized lists, Formalizer/Judge rewrite or classify text tone, Estimator predicts task duration, Chef plans meals from constraints. Architecturally it's one LLM core surfaced through many tiny composable frontends, each doing one prose-to-structure (or structure-to-prose) transform.

GRABS:
  [ASPECT] Recursive task decomposition with a granularity dial: break a goal into verb-noun actions, then re-run the same decomposition on any subtask, with one scalar ('spiciness level') mapped into the prompt to control output granularity
      Directly portable into the local agents they already run for research and document processing — it's a reusable prompt pattern, not a product. The single-knob granularity control is exactly the kind of 'structured in/out for machines' mechanism they value, and it'd work fine over OpenRouter or a small local model instead of Goblin Tools' cloud backend.

  [ASPECT] The Compiler pattern: an LLM stage that ingests unstructured brain-dump prose and emits organized, structured lists
      This is literally their ingest pipeline philosophy — 'markdown in, structured queues out' — applied to human messiness.   [ASPECT] One shared LLM backend with many tiny single-purpose frontends, each a narrow prose transform (decompose, reformat, classify, estimate)
